# 兼容性证据

结论先说：**工具与汉化补丁、宽屏 / 分辨率补丁、HD 补丁互不影响**，可任意组合。原因是工具只改写 `RoadRash95.exe` 文件偏移 `0x195490` 起的 3840 字节（`.data` 段内的 15 张 LUT），以及 v2.0 在必要时改写 `DATA/PALETTE.RAW` 的若干 RGB；而上述补丁改的是 PE 头、资源段与文件尾部新增节。

界面里的 **兼容性自检 / Compatibility Check** 按钮会在你的机器上现场重算下列项目。

---

## 1. 补丁安装前后，表区零差异

在装齐「汉化 + 宽屏分辨率 + HD」补丁的机器上，用补丁安装前的 exe 备份与安装后的 exe 逐字节比较：

| 项 | 安装前 | 安装后 |
|---|---|---|
| 文件大小 | 1,803,264 B | 1,804,800 B |
| `.data` 段 raw 偏移 | `0x18CA00` | `0x18CA00` |
| 表区（3840 B） | 完全一致 | 完全一致 |
| 表区 FNV-1a | `0x51D083B966BD8657` | `0x51D083B966BD8657` |

差异全部落在 PE 头、资源段和文件尾部新增节（HD 补丁添加的 `.rrhd` 只是导入桩）。表区内差异数为 **0**，表区之前也没有差异。

## 2. 游戏 DLL 不会在运行时覆盖表

扫描以下 DLL 中对表区 VA `0x596A90` / RVA `0x196A90` / 文件偏移 `0x195490` 的 32 位小端引用：

| DLL | 命中数 |
|---|---|
| `RoadRashHD.dll` | 0 |
| `RASHICON.DLL` | 0 |
| `RASHPROP.DLL` | 0 |
| `AWEMAN32.DLL` | 0 |

`.rrhd` 段只是导入桩，不含配色数据，也不会回写这张表。

## 3. 汉化补丁

改的是资源段与文本，不落在 `.data` 的表区内，因此与本工具无关。

## 4. `PALETTE.RAW` 与 HD 补丁

v2.0 会读 / 写 `DATA/PALETTE.RAW`。静态检查 + 受控探针结论：

- 全游戏目录只有这一份 1024 字节（256 × RGBA）调色板，exe / DLL 无内嵌副本。
- MultiFix 的 `hd_renderer.cpp` 中，HD 渲染器 hook 的 `present8` 收到同格式 256×RGBA 表并上传 GPU，`compose()` 用它把 8-bit 索引转 RGB —— 即 HD 渲染路径**仍然使用这张表**，没有绕过。
- 探针实测：临时把 idx 2/3/4 写成 `12 34 56 00 78 9A BC 00 DE F0 21 00`，启动游戏后扫描进程内存，原样命中该序列。改 `PALETTE.RAW` 确实生效。

## 会让修改失效的情况

| 情况 | 后果 | 处理 |
|---|---|---|
| Steam「校验游戏文件完整性」 | 还原 exe / 调色板 | 重新用工具应用一次 |
| 游戏更新 | 可能还原或改动 exe 布局 | 重新应用；若表头校验失败说明版本已变，需重新定位表区 |
| 重装汉化 / HD / 分辨率补丁（替换了 exe） | 还原表区 | 重新应用一次 |
| `MultiFix` 开启 `FixBikeColors` | 只在表区哈希等于原版时交换 | 自定义配色不会被覆盖 |

## 安全边界

- 仅适用于 **Steam 30 周年版 exe**。写前会逐张校验 15 张表的 `00 01` 表头特征与文件长度，版本不符或表被其它 mod 重定位时会**拒绝写入**。
- 写盘前为 exe（以及 v2.0 的 `PALETTE.RAW`）各创建带时间戳的备份；写后逐字节回读比对；v2.0 双文件任一失败自动回滚两者，避免「改了调色板但没改 exe」的半套状态。
- 表区之外**一个字节都不碰**：PE 头、节数、导入表、资源、`.rrhd` 桩全部保持原样。
- 应用前请确认游戏已完全退出（含后台进程），否则文件可能被占用；工具会给出明确提示。
